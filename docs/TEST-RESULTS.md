## 公開準備時の再確認 — 2026-10-13

- アプリとworkerのReleaseビルドに成功。NuGet脆弱性情報のサービスへ接続できず、NU1900警告あり。
- 既存8項目の回帰テストに合格: 120分既定値と旧60分設定維持、通常無音分割、強制分割とoverlap、無パケット補完、PCM復旧、設定保存、安全なTXT結合、リサンプル。
- 音声ファイルを配布せず、Windows SAPIで診断用音声を実行時生成する設計に変更。この実行環境では音声列挙が0x80045039で失敗し、音声合成から録音・認識までの再検証は未完了。
- 通常録音はSAPIや同梱テスト音声に依存しない。モデルの整合性を確認して録音し、最初の実音声チャンクでbackend初期化とfallbackを実行する。

**記録:** 下記は旧バージョンの検証記録です。今回テスト音声ファイルを除き、Windows SAPIで実行時に合成する方式へ変更しました。この変更後の音声合成・文字起こし経路は未検証です。完全ミュート・120分の旧版実機記録は`MUTED-CAPTURE-UPDATE.md`を参照してください。

実行環境: Windows 11の開発用デスクトップでネイティブビルド・実行。CPU、GPU、接続機器の詳細はREADMEに記載した範囲にとどめる。WSL、Linuxコンテナ、クラウド認識は使用していない。

## 実測の参考値

開発時の初期診断では短い音声を用いた速度測定を実施。後にVAD処理を改良しており、旧測定値は現行速度を保証しない。README記載の開発用PCでは快調に動作。

## 発見して修正した不具合

- RIFFの追加metadataを含むWAVを正しく走査するよう修正。
- native logの実際のGPU割当形式に合わせて成功判定を修正。
- VADで発話がないチャンクをGPU故障と誤判定しないよう修正。
- 近接するVAD区間を最大30秒までまとめ、短い固有名詞区間へのプロンプトの過剰な影響を軽減。
- 再生を録音対象と同じMultimedia endpointへ明示。
- 録音停止後の時計を固定し、停止後に時間が増え続けないよう修正。

## 未検証・制約

- 3時間連続の実録音、実際の電源断、異なるGPU構成、別PCの完全なクリーン環境。
- Bluetooth/USB/HDMIの物理抜去・既定デバイス変更全パターン。
- 実機の自動スリープ移行を待つ試験。抑止・解除APIは実録音経路で呼んでいる。
- large-v3 / medium の実推論。設定、公式取得、ハッシュ検証、fallback経路は実装済み。実認識試験はlarge-v3-turboで実施。
- GUI画面を外部操作ツールで目視操作する試験は、アプリ承認タイムアウトにより未完了。起動・診断・主要処理のネイティブ実行とは区別する。
- Windowsが音量0・ミュートの状態では、この既定出力で無音しか取得できなかった。10%・ミュート解除で成功。開発試験後に元の状態へ復元。通常録音は音量を変更しない。
